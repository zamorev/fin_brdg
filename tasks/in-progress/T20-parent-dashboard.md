# T20 — Родитель видит запросы, подростков, их бюджет и категории

## Description

Сегодня записываем видео для хакатона. Нужно показать родительскую сторону по макету (Claude Design «Fin Bridge — родитель», спека «Fin Bridge — спецификация экранов родителя»), почти не трогая сценарий подростка:

1. запросы подростка приходят родителю;
2. каждого подростка можно открыть — бюджет недели и категории;
3. сумма категории меняется и родителем напрямую, и по запросу подростка.

Решения и разбор противоречий — [parent-screens.md](../../docs/design-docs/parent-screens.md) (D1–D11, раздел 11 — объём для видео).

Ключевое: запрос подростка теперь «+N ₽ к недельному бюджету» (D11), при одобрении прибавка ложится в резерв. Категории фиксированные (5 из `domain.ts`), у родителя видны суммы плана подростка и минимумы.

Заменяет прежний текст T20 (блоки «Договорённости / Квесты / Навыки» на старом API).

## Acceptance Criteria

### Домен (обе копии)
- [ ] Проверка запроса: прибавка > 0, ≤ 500 ₽, шаг 50, объяснение обязательно
- [ ] Проверка правки родителя: суммы ≥ 0, минимумы, сумма категорий = недельному бюджету
- [ ] Тесты в `domain.test.ts`

### API и данные
- [ ] `POST /api/requests { increase, explanation }` — запрос `kind: "weekly_budget"` с `teenTelegramId`
- [ ] Одобрение: бюджет подростка = новая сумма (или своя сумма родителя), прибавка → резерв; старые запросы «развлечения» решаются как раньше
- [ ] `PATCH /api/teens/:telegramId/agreement { allocation, weeklyBudget }` — только родитель своей семьи
- [ ] `firestore-schema.md` обновлена; демо-семья создаёт запрос в новом формате

### Родитель (UI, тема Telegram)
- [ ] Главная: шапка, карточка запросов (если есть), список подростков со статусом и бюджетом, «Семья»
- [ ] «Запросы»: вкладки, карточка запроса (было → стало, почему, последствия), Одобрить / Отклонить / Своя сумма / Расскажи ещё, итог, «Недавно решено», «История» — заглушка
- [ ] Экран подростка: заглушки «3 уровень · N квестов» (N из данных семьи), баннер запроса, бюджет недели с −/+, полоса распределения, статус, категории (сумма плана крупно, «мин. N ₽» мелко)
- [ ] Шторка категории: степпер, чипы, «Откуда взять» (резерв / увеличить бюджет), сохранение
- [ ] Перезапрос сессии при возврате в Mini App

### Подросток

- [ ] Строка запроса на главной: «Бюджет недели: X → Y ₽»
