# T22 — Договорённость и остаток недели — разные числа

## Description

В `families.allocation` смешаны **правила** (договорённость семьи по категориям) и **остаток** (сколько осталось после трат). Видно на прогоне API:

1. Квест 1 → план 1 500 ₽. «Незапланированная покупка» → из накоплений −250 ₽ (тот же `allocation`).
2. Родитель одобряет «развлечения 500» → `allocation.entertainment = 500` поверх уже потраченного. Сумма 1 450 ₽, а главная пишет «бюджет на эту неделю 1 500 ₽».
3. Сценарий «Ой, кино» тратит 600 ₽ из развлечений 400 → `Math.max(0, …)` молча обрезает до 0, **дефицит не виден**. DoD п. 2 требует «отображение последствий и **дефицита**».

Плюс тексты сценария: «Билет — 300 ₽», затем «стоит 250 ₽»; ветка «друзья заплатят за тебя» всё равно списывает 250 ₽.

Плюс решение родителя: после «Нужно уточнение» запрос финален — ответить подросток не может (X3), только новый запрос.

**Сначала решение, потом код:** короткий дизайн-док и согласование с командой (продуктовое решение, затрагивает данные в prod).
