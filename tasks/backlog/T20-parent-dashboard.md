# T20 — Родитель видит правила, квесты, навыки и запрос

## Description

Закрывает пункты 4–5 DoD ([PRODUCT.md](../../docs/PRODUCT.md#definition-of-done-dod)): «Родитель видит правила, результаты квестов, навыки и запрос… при одобрении обновлённые правила отображаются у подростка и у родителя».

**Бэкенд готов:** `GET /api/me` для родителя уже отдаёт `family.allocation`, `questWeekBudgetCompleted`, `questUnplannedCompleted`, `unplannedChoice`, `skills`, `level`, `activeRequest` (проверено прогоном API). Сейчас главная родителя (разметка прямо в `App.tsx`) показывает только запрос, «Еженедельный бюджет» (T17) и «Семью».

Заодно у подростка кнопка **«Мои договорённости»** ведёт в никуда (`onOpenAgreements={goHome}`) — общий экран правил нужен обеим ролям.

Аналог из v1: [archive/T07](../archive/T07-parent-dashboard.md), [archive/T09](../archive/T09-parent-request-decision.md).

## Acceptance Criteria

- [ ] Главная родителя вынесена из `App.tsx` в `screens/ParentHome.tsx`
- [ ] Блок **«Договорённости»**: все 5 категорий с суммами (подписи — `CATEGORY_LABELS`, числа — из `family.allocation`)
- [ ] Блок **«Квесты подростка»**: «Неделя на 1 500 ₽» — пройден/нет; «Незапланированная покупка» — пройден/нет и выбранный вариант
- [ ] Блок **«Навыки»**: список `skills`; пустое состояние, если навыков нет
- [ ] Блок **запроса**: категория, было → предложено, объяснение, статус (`REQUEST_STATUS_LABELS`), комментарий родителя после решения; переход в `ParentRequest`
- [ ] После решения «Одобрить» родитель возвращается на главную и **видит обновлённые договорённости** без перезапуска
- [ ] Экран `Agreements.tsx` (правила по категориям) открывается у **обеих ролей**; у подростка — по «Мои договорённости»
- [ ] Блок «Еженедельный бюджет» (T17) сохранён
- [ ] Тексты — по [tone-of-voice.md](../../docs/design-docs/tone-of-voice.md); пустые состояния для семьи без подростка / без квестов
- [ ] Smoke кликами (вход за родителя из T19, демо-семья): главная родителя → запрос → «Одобрить» → договорённости обновились; у подростка «Мои договорённости» открываются
- [ ] `./scripts/verify.sh` OK
