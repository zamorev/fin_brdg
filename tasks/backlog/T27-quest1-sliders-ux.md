# T27 — Квест «Неделя на 1 500 ₽»: удобные ползунки и понятный итог

## Description

Правки после прода (роль — подросток), экран `QuestBudget`. Четыре проблемы:

1. **Ползунок трудно «поймать».** Чтобы начать двигать, нужно точно попасть пальцем в бегунок или нажать дважды. Причина не подтверждена. Гипотезы: нативный `<input type="range">` без стилей — бегунок маленький; в WebView Telegram (особенно iOS) тап по дорожке не переносит бегунок; жест конфликтует с прокруткой страницы. `disableVerticalSwipes()` уже вызывается в `TwaProvider`.
2. **Кнопка «Проверить мой бюджет» «выезжает» снизу после каждого изменения.** Причина найдена в коде: `QuestBudget` передаёт в `MainAction` новую функцию `onClick={() => void onCheck()}` на каждый рендер. Эффект в `MainAction` зависит от `onClick`, поэтому при каждом сдвиге ползунка он делает `hideMainButton()` и через 450 мс заново показывает Telegram MainButton. Такая же схема на всех экранах с `MainAction` (`NewConditions`, `ParentRequest`, `ScenarioStep`, `RequestSent`), но там значения не меняются так часто, поэтому не заметно.
3. **Ползунок можно увести ниже минимума категории.** Сейчас у всех ползунков `min={0}` и нет ограничения. Минимум проверяется только при нажатии кнопки (`validateAllocation`). В Streamlit-версии (T04, `clamp_amount`) бегунок возвращался на минимум.
4. **Итог не показывает перебор и не объясняет, что делать.** Сейчас цифра «Распределено» бывает только зелёной (ровно) или жёлтой `--fb-warning` (всё остальное). Красного для перебора и строки-подсказки нет. В T04 было «Осталось распределить / Перебор / Всё распределено».

**Предложение владельца:**

- Кнопка внизу стоит **статично**, не мигает и не прячется при изменениях.
- Общая шкала 0 – недельный бюджет. Ниже минимума категории ползунок увести нельзя: при попытке бегунок остаётся на минимуме.
- У категории без договорённости (сейчас «Развлечения», минимума нет) ползунок от 0.
- Цвет суммы: зелёный — распределено ровно, оранжевый — недобор, **красный — перебор** (тон как у зелёного и оранжевого).
- Под суммой серым (`--fb-hint`) — строка после каждого изменения: «Осталось распределить 50 ₽» / «Распределено на 50 ₽ больше» / «Бюджет распределён полностью». Тексты по [tone-of-voice.md](../../docs/design-docs/tone-of-voice.md).

**Сначала план и проверка готовности кода, потом реализация** (требование владельца).
