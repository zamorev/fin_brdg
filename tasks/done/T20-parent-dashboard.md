# T20 — Родитель видит запросы, подростков, их бюджет и категории

## Description

Сегодня записываем видео для хакатона. Нужно показать родительскую сторону по макету (Claude Design «Fin Bridge — родитель», спека «Fin Bridge — спецификация экранов родителя»), почти не трогая сценарий подростка:

1. запросы подростка приходят родителю;
2. каждого подростка можно открыть — бюджет недели и категории;
3. сумма категории меняется и родителем напрямую, и по запросу подростка.

Решения и разбор противоречий — [parent-screens.md](../../docs/design-docs/parent-screens.md) (D1–D11, раздел 11 — объём для видео).

Ключевое: запрос подростка теперь «+N ₽ к недельному бюджету» (D11), при одобрении прибавка ложится в резерв. Категории фиксированные (5 из `domain.ts`), у родителя видны суммы плана подростка и минимумы.

Заменяет прежний текст T20 (блоки «Договорённости / Квесты / Навыки» на старом API).
