# T26 — Выход из «Семьи» — в левом верхнем углу

## Description

Правка после прода (роль — подросток, но экран общий для обеих ролей).

Сейчас на экране «Семья» кнопка **«Готово»** (`btn-primary-scroll`, вызывает `onDone` → `goHome`) стоит в самом конце, после списков родителей/подростков и подсказки. Чтобы выйти, приходится долистывать вниз — неудобно и неочевидно.

**Предложение:** убрать «Готово» снизу, поставить кнопку выхода **сверху в левом углу**, над заголовком «Fin Bridge / Семья», в виде текстовой ссылки **«← Назад»** (цвет `--fb-link`, как у существующих `text-link`, но выровнена влево и компактная).

Что уже есть в коде:

- `FamilyScreen` получает два колбэка: `onBack` (Telegram BackButton, через `backFromFamily` с guard 800 мс) и `onDone` (явный выход, без guard). Новая кнопка — это `onDone`, менять `App.tsx` не нужно.
- В TWA уже есть нативная «Назад» в шапке Telegram (`useBackAction(onBack, 650)`) — её **не трогаем**, новая кнопка дублирует её внутри страницы.
- Готового стиля «назад сверху слева» в проекте нет: `text-link` — по центру, на всю ширину (`OnboardingScreen`, `RequestSent`). Нужен новый класс, например `.screen-back`.
- Отступ сверху в полноэкранном режиме Telegram задаёт `--fb-content-top` (`TwaProvider` → `topInset`) — кнопка должна оказаться под системными кнопками Telegram, а не под ними.
