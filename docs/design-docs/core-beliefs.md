# Core beliefs (золотые правила)

Сжатые инварианты. Не дублировать в `AGENTS.md` — только ссылка сюда.

## Продукт

1. **Условные деньги**, не банк: никаких реальных счетов и ядра ВТБ в MVP.
2. **Правила меняет только родитель** после явного решения; подросток лишь запрашивает.
3. **Без рейтинга доверия** и авто-лимитов по «зрелости».
4. Один продукт, **две роли** — разные Telegram-аккаунты (подросток / родитель), без переключателя роли в UI; вход через **@fin_brdg_bot**.
5. Пользовательские тексты — по [tone-of-voice.md](tone-of-voice.md); готовые фразы бота — [TELEGRAM_BOT.md](../TELEGRAM_BOT.md).

## Код

1. **Домен и квесты** не импортируют Streamlit.
2. **UI не содержит SQL** — только `src/db`.
3. **Числа бюджета** живут в `src/domain`; UI и квесты импортируют.
4. **Одна задача — одна ветка — один PR**; зоны из `harness/OWNERSHIP.md`.
5. Перед «готово» — `./scripts/verify.sh` (или эквивалентные команды из вывода скрипта).

## Контекст для агентов

1. Решения из Slack/устно **не существуют**, пока не попали в git (`docs/` или задача).
2. Не раздувать `AGENTS.md`: правки в `docs/` или в задачу.
