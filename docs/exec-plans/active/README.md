# Active execution plans

Крупные эпики (несколько задач, одна цель) — опционально для хакатона.

Формат файла `epic-<name>.md`:

- Goal
- Tasks (Txx…)
- Decisions log (дата, решение, почему)
- Status

Сейчас основной трек — очередь `tasks/backlog/` T01–T10. Эпик-планы добавляйте, если команда делит «День 1 / День 2» между людьми.
