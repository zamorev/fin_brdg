# Active execution plans

Крупные эпики (несколько задач, одна цель) — опционально для хакатона.

Формат файла `epic-<name>.md`:

- Goal
- Tasks (Txx…)
- Decisions log (дата, решение, почему)
- Status

Сейчас основной трек — [epic-dod.md](epic-dod.md): задачи T18–T24 до готовности по DoD. Эпик-планы добавляйте, если работа делится между людьми на несколько связанных задач.
