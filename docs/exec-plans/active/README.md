# Active execution plans

Крупные эпики (несколько задач, одна цель) — опционально для хакатона.

Формат файла `epic-<name>.md`:

- Goal
- Tasks (Txx…)
- Decisions log (дата, решение, почему)
- Status

Сейчас основной трек — очередь `tasks/` (backlog → in-progress → done). Эпик-планы добавляйте, если работа делится между людьми на несколько связанных задач.
